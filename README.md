### About Project
The goal of this project is to create a quick, lightweight small-medium doc analyze,
letting users ask specific questions that are answered in doc (if present)

# How it works
The user uploads their docs into the website, and asks the AI/Chat specific questions
about their docs to get an extremely accurate answer

### Backend
Backend built on FastAPI and Uvicorn. 

# To run
activate venv, and run "python backend/main.py"

### FrontEnd
Frontend build on React/TS/Tailwind

# To run
run the command "npm run dev"
